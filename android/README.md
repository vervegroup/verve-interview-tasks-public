# Android SDK - Coding Interview Starter

Welcome! This is a starter project for the Android coding interview.

## Prerequisites

- Android Studio (latest stable version recommended)
- Java 8 or higher
- Android SDK (API level 24+)

## Setup

1. Clone this repository
2. Open the project in Android Studio
3. Sync Gradle dependencies
4. Build the project to ensure everything is set up correctly

**Important:** Please make sure the project builds successfully before the interview to save time on setup.

## Project Structure

```
android-sdk-coding-interview-starter/
├── verve-demo-app/              Demo app module
│   └── src/main/java/com/verve/android/interviewkit/demo/
│       └── MainActivity.java
│
└── verve-interstitial-ad/       SDK module
    └── src/main/java/com/verve/android/interviewkit/
        ├── VerveInterstitialAd.java
        ├── VerveInterstitialAdListener.java
        └── activity/
            └── InterstitialActivity.java
```

## Running the App

1. Select the **verve-demo-app** run configuration
2. Choose an Android Emulator or physical device
3. Click Run

The app will launch with a simple UI. Implementation details will be discussed during the interview.

## Notes

- The project uses standard Android Gradle setup
- All necessary dependencies are already configured
- Problem statement and requirements will be provided during the interview session

Good luck! 🚀
